# 08. HTTP 接口：功能、调用方式与响应语义

本文列出应用当前注册的业务 HTTP 接口，并说明身份要求、调用顺序、异步任务与 SSE 的使用方式。

## 1. 提供哪些功能

```text
HTTP 接口
├── 认证（登录用户）
│   ├── 用户名或邮箱登录
│   ├── 刷新令牌与退出登录
│   └── 读取当前用户与修改密码
├── 用户管理（平台管理员）
│   ├── 分页查询用户
│   ├── 创建用户
│   ├── 修改资料、密码、管理员标记与 Doris 角色绑定
│   └── 受理用户注销
├── Doris 角色与权限（平台管理员）
│   ├── 查询平台角色、Doris 已有角色和工作组
│   ├── 创建或删除角色及查询身份
│   ├── 设置或清除新用户默认角色
│   ├── 查询、授予和撤销指定 SELECT 权限
│   ├── 撤销角色在当前数据库中的全部 SELECT 权限
│   └── 查询、创建和删除行级策略
├── 元数据目录（平台管理员）
│   ├── 查询表目录、来源表、字段和指标
│   ├── 创建或更新表、字段和指标
│   ├── 批量删除表、字段或指标
│   ├── 预检 YAML 变更并提交正式导入
│   └── 导出当前业务目录
├── 元数据索引（平台管理员）
│   ├── 提交指定表内字段的语义索引同步
│   ├── 提交指定字段或指标的语义索引同步
│   ├── 按表或字段提交全量、增量取值同步
│   └── 通过目录响应读取索引版本与字段取值同步状态
├── 查询经验（平台管理员）
│   ├── 按角色、状态和文本分页筛选经验
│   ├── 读取经验详情与来源执行记录
│   ├── 单条或批量禁用经验
│   └── 单条或批量受理经验删除
├── 会话目录（当前用户，创建需分析资格）
│   ├── 创建草稿或正式会话
│   ├── 读取会话列表和消息历史
│   ├── 更新会话标题
│   ├── 批量请求删除会话或单独删除草稿
│   └── 读取指定专家委派的历史消息
├── 运行控制（具备分析资格的用户）
│   ├── 发送输入并订阅 SSE
│   ├── 恢复未完成工作并订阅 SSE
│   ├── 查询当前 Run 状态
│   ├── 重新订阅当前 Run 的事件
│   └── 停止当前 Run
├── 附件（当前用户，上传需分析资格）
│   ├── 上传文件并取得会话附件引用
│   ├── 读取或下载用户附件及分析产物
│   └── 删除用户上传的附件
└── 后台任务（平台管理员）
    ├── 按任务 ID 查询状态和是否完成
    └── 读取任务成功结果或失败信息
```

## 2. 如何调用

### 2.1 地址与认证

默认本地后端地址为 `http://localhost:7000`，业务路径以 `/api/v1` 开头。请求模型与响应字段由运行中的 `/docs` 和 `/openapi.json` 提供。

| 操作 | 凭据传递方式 |
| --- | --- |
| 登录 | 请求体传入用户名或邮箱及密码 |
| 调用受保护接口 | 请求头传入 `Authorization: Bearer <access_token>` |
| 刷新令牌 | 请求体传入 Refresh Token；成功后保存新令牌对 |
| 退出登录 | 请求体传入要撤销的 Refresh Token |

客户端串行使用同一 Refresh Token，避免并发刷新触发重放检查。

| 访问层级 | 检查内容 | 主要接口 |
| --- | --- | --- |
| 登录凭据 | 用户名或邮箱及密码，应用登录限流 | login |
| 刷新凭据 | Refresh Token，应用刷新限流 | refresh |
| 当前用户 | JWT、账号状态和版本，必要时会话归属 | me、改密、用户自己的资源 |
| 分析资格 | 已认证且绑定可用 Doris 查询身份 | Agent 执行及对应路由要求的会话操作 |
| 平台管理员 | 已认证且 is_admin | 用户、角色、元数据、经验与任务状态管理 |

各端点的依赖决定实际访问要求。会话、附件与专家历史同时检查用户归属。

### 2.2 常见调用顺序

**用户开始分析**

1. 登录并保存令牌。
2. 创建会话，取得 Conversation ID。
3. 按需上传附件。
4. 调用 stream 发送消息，持续读取 SSE。

**断线后继续查看**

1. 查询 run 状态。
2. 仍在运行时订阅 events；已完成时读取会话历史。

**恢复或停止工作**

| 操作 | 调用与后续处理 |
| --- | --- |
| 继续未完成工作 | 调用 resume 恢复图中待执行任务，读取 SSE |
| 停止分析 | 调用 stop 请求取消当前 Run，再查询状态或历史 |

**初始化业务目录**

1. 调用 import 预检变更。
2. 提交正式导入。
3. 查询后台任务状态。
4. 查看目录及索引版本。

**注销账号**

1. 管理员请求删除用户。
2. Worker 在后台清理资源。
3. 通过用户是否仍存在、持久化注销状态及任务日志确认进度。

断开 SSE 连接只释放订阅，运行任务由显式 stop 请求取消。多 API 进程部署需将 run、events 和 stop 请求路由到拥有该 Run 的进程。

## 3. 接口清单

路径参数使用 `{name}`。下列方法与路径对应当前注册路由。

### 3.1 认证

登录校验账号密码，刷新和登出使用请求中的 Refresh Token；改密与当前用户查询要求有效的 Access Token。登出撤销刷新令牌族，不要求额外提供 Bearer Token。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/api/v1/auth/login` | 登录并签发令牌 |
| `POST` | `/api/v1/auth/refresh` | 刷新访问令牌 |
| `POST` | `/api/v1/auth/logout` | 退出登录，撤销刷新令牌 |
| `POST` | `/api/v1/auth/change-password` | 修改当前用户密码 |
| `GET` | `/api/v1/auth/me` | 读取当前用户信息 |

### 3.2 用户与 Doris 角色

这些操作需要平台管理员身份。Doris 管理动作使用后台管理连接，普通分析查询使用角色对应的查询身份。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/v1/admin/doris-roles` | 列出平台管理的 Doris 角色 |
| `POST` | `/api/v1/admin/doris-roles` | 创建 Doris 角色及查询身份 |
| `GET` | `/api/v1/admin/doris-roles/workload-groups` | 列出 Doris 资源工作组 |
| `GET` | `/api/v1/admin/doris-roles/existing` | 列出 Doris 中已有角色 |
| `PUT` | `/api/v1/admin/doris-roles/{role}/default` | 设置新用户的默认角色 |
| `DELETE` | `/api/v1/admin/doris-roles/default` | 清除默认角色 |
| `DELETE` | `/api/v1/admin/doris-roles/{role}` | 删除 Doris 角色 |
| `GET` | `/api/v1/admin/users` | 分页查询平台用户 |
| `POST` | `/api/v1/admin/users` | 创建平台用户 |
| `DELETE` | `/api/v1/admin/users/{user_id}` | 受理用户注销 |
| `PUT` | `/api/v1/admin/users/{user_id}` | 更新用户资料、管理员标记或角色 |
| `GET` | `/api/v1/admin/doris-roles/{role}/select-grants` | 查询 SELECT 授权 |
| `POST` | `/api/v1/admin/doris-roles/{role}/select-grants` | 授予 SELECT 权限 |
| `DELETE` | `/api/v1/admin/doris-roles/{role}/select-grants` | 撤销指定 SELECT 权限 |
| `DELETE` | `/api/v1/admin/doris-roles/{role}/select-grants/all` | 撤销全部 SELECT 权限 |
| `GET` | `/api/v1/admin/doris-roles/{role}/row-policies` | 查询行级策略 |
| `POST` | `/api/v1/admin/doris-roles/{role}/row-policies` | 创建行级策略 |
| `DELETE` | `/api/v1/admin/doris-roles/{role}/row-policies` | 删除行级策略 |

### 3.3 查询经验

管理员可以查看、禁用和删除经验。接口没有独立的“恢复经验”操作；元数据失效后的重新激活由成功查询规则决定，管理员主动禁用不会被自动恢复。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/v1/admin/query-experiences` | 分页筛选查询经验 |
| `POST` | `/api/v1/admin/query-experiences/batch-disable` | 批量禁用查询经验 |
| `POST` | `/api/v1/admin/query-experiences/batch-delete` | 批量删除查询经验 |
| `GET` | `/api/v1/admin/query-experiences/{experience_id}` | 读取单条查询经验 |
| `DELETE` | `/api/v1/admin/query-experiences/{experience_id}` | 删除单条查询经验 |
| `GET` | `/api/v1/admin/query-experiences/{experience_id}/executions` | 查看经验关联的执行记录 |
| `POST` | `/api/v1/admin/query-experiences/{experience_id}/disable` | 禁用单条查询经验 |

### 3.4 会话与运行控制

这些接口校验登录身份和会话归属。流式接口使用 SSE；开始执行、订阅已有执行和停止执行是不同操作。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/api/v1/chat/create` | 创建会话，通过 is_draft 指定草稿 |
| `POST` | `/api/v1/chat/delete` | 批量请求删除会话 |
| `DELETE` | `/api/v1/chat/draft/{conversation_id}` | 删除草稿会话 |
| `POST` | `/api/v1/chat/update` | 更新会话信息 |
| `GET` | `/api/v1/chat/ls` | 列出当前用户会话 |
| `GET` | `/api/v1/chat/ls/{conversation_id}` | 读取会话历史 |
| `GET` | `/api/v1/chat/{conversation_id}/subagents/{analysis_id}/{agent_type}/{session_id}/runs/{delegation_id}/messages` | 读取指定专家委派的消息 |
| `POST` | `/api/v1/chat/stream` | 发送消息并接收流式事件 |
| `POST` | `/api/v1/chat/{conversation_id}/resume` | 继续执行会话 |
| `GET` | `/api/v1/chat/{conversation_id}/run` | 查询当前 Run 状态 |
| `GET` | `/api/v1/chat/{conversation_id}/events` | 订阅当前 Run 的事件 |
| `POST` | `/api/v1/chat/{conversation_id}/stop` | 停止当前 Run |

### 3.5 会话附件

附件访问同时受用户、会话及路径规则约束，客户端提供路径不等于获得任意文件访问权。

| 方法 | 路径 | 用途 |

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/v1/tasks/{task_id}` | 查询后台任务状态 |

## 4. 响应与执行规则

| 操作 | HTTP 返回的含义 | 后续状态来源 |
| --- | --- | --- |
| 普通账号、目录读写 | 当前用例完成或失败 | 返回内容与当前数据库状态 |
| 元数据 dry_run | 已完成预检，没有应用变更 | 新增、更新与删除清单 |
| 正式导入 | 后台导入任务已提交 | 任务结果及目录版本 |
| 索引同步 | 后台同步任务已提交 | 任务结果及索引版本 |
| 用户注销 | 账号已禁用、注销任务已受理 | 持久化注销状态与实际资源清理 |
| Conversation 删除 | 标记并安排清理 | 会话生命周期状态，忙碌时可能拒绝 |
| SSE 启动 | 开始订阅本次执行 | 事件流、Run 状态及持久历史 |
| SSE 恢复 | 开始订阅恢复的执行 | 事件流、Run 状态及持久历史 |
| SSE 重新订阅 | 订阅当前进程持有的 Run | 有界事件重放与实时事件 |
| Run 停止 | 请求取消本进程的运行 | 取消收尾与状态查询 |

接口失败可能发生在部分跨系统操作之后。元数据目录可能已提交、Doris 授权可能已改变、部分索引任务可能已入队，不能一律按 HTTP 失败推断全部回滚。

**任务状态与业务状态**

| 状态来源 | 用途与限制 |
| --- | --- |
| `GET /api/v1/tasks/{task_id}` | 查询任务结果；结果有保留期限，过期或未知 ID 也可能返回 PENDING |
| 业务数据库 | 保存注销受理、清理进度及目录和索引版本 |

**错误响应**

| 失败阶段 | 返回方式 |
| --- | --- |
| 请求参数无效 | HTTP 422 |
| 认证或授权失败 | 按具体业务错误返回 HTTP 状态 |
| SSE 已开始后失败 | `error` 事件 |

SQL 执行、Shell 和 Agent 文件操作通过运行上下文中的工具调用，绑定服务端用户与 Session。HTTP 管理接口用于账号、目录和经验管理。

后端 Pydantic 模型定义请求与响应。修改协议后在项目根目录同步前端类型：

```bash
uv run python scripts/development/generate_openapi_types.py
uv run python scripts/development/generate_openapi_types.py --check
```

生成结果位于 `web/src/api/generated.ts`。

## 5. 异常与排障

| 现象 | 检查内容 |
| --- | --- |
| 401 | Access Token 有效期和认证版本；刷新失败时重新登录 |
| 403 | 账号状态、管理员资格、分析角色和资源访问条件 |
| 404 | 资源是否存在、会话是否属于当前用户、是否已删除 |
| 409 | 资源冲突、会话执行锁或业务状态冲突，以错误类型为准 |
| 422 | 请求字段、类型及跨字段约束，查看错误中的字段位置 |
| 429 | Retry-After 和认证限流 |
| SSE 中途报错 | 已收到的事件、run 状态及服务端日志 |
| 任务长期 PENDING | ID 是否正确、结果是否过期、Worker 与队列路由 |
| 修改接口失败但数据已保存 | 是否已提交业务事务，后续任务投递或跨存储操作是否失败 |

普通错误采用 `application/problem+json`。流已开始后的失败通过 error 事件表达，客户端应同时处理 HTTP 建连错误和流内错误。
