# 08. HTTP 接口索引与调用边界

本文按模块列出当前注册的业务 HTTP 操作、访问要求与执行语义。具体字段以运行服务的 OpenAPI 为准；模块内部实现由各模块说明文档介绍。

## 1. 接口约定与访问层级

下表列出当前应用注册的全部业务 HTTP 操作。路径参数用 `{name}` 表示；参数位置、请求体、分页字段和响应结构以运行中的 `/docs` 或 `/openapi.json` 为准。默认本地文档地址为 `http://localhost:7000/docs`。

后端使用 Pydantic 定义接口数据，前端通过 OpenAPI 生成 TypeScript 类型。修改请求或响应时，应修改后端定义并重新生成类型，避免手动维护另一份相似结构。常规错误采用统一 Problem Details；流已经开始后的错误通过流事件表达，不能再简单替换 HTTP 状态码。

| 入口 | 身份要求 |
| --- | --- |
| `GET /api/v1/users` | 无需预先选择用户，返回预定义用户列表 |
| 会话、运行控制、附件接口 | 请求头 `X-User-ID` 指定存在的用户，并检查资源归属 |

用户选择不进行密码认证。业务 SQL 使用所选用户对应的 Doris 查询身份，仍受该角色数据权限约束。应用不再提供认证、用户管理、角色管理或后台任务状态接口。

## 4. Conversation 与运行控制接口

这些接口校验所选身份和会话归属。流式接口使用 SSE；开始执行、订阅已有执行和停止执行是不同操作。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/api/v1/chat/create` | 创建草稿会话 |
| `POST` | `/api/v1/chat/delete` | 批量请求删除会话 |
| `GET` | `/api/v1/chat/ls` | 列出当前用户会话 |
| `GET` | `/api/v1/chat/ls/{conversation_id}` | 读取会话历史 |
| `POST` | `/api/v1/chat/stream` | 发送消息并接收流式事件 |
| `POST` | `/api/v1/chat/{conversation_id}/resume` | 继续执行会话 |
| `GET` | `/api/v1/chat/{conversation_id}/run` | 查询当前 Run 状态 |
| `GET` | `/api/v1/chat/{conversation_id}/events` | 订阅当前 Run 的事件 |
| `POST` | `/api/v1/chat/{conversation_id}/stop` | 停止当前 Run |

## 5. 会话附件接口

附件访问同时受用户、会话及路径规则约束，客户端提供路径不等于获得任意文件访问权。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/v1/chat/attachment/get` | 读取或下载会话附件 |

## 7. 同步响应、任务受理与流式执行

| 操作 | HTTP 返回的含义 | 后续状态来源 |
| --- | --- | --- |
| 用户列表 | 当前读取完成或失败 | 已初始化的预定义用户 |
| Conversation 删除 | 标记并安排清理 | 会话生命周期状态，忙碌时可能拒绝 |
| SSE 启动/恢复 | 开始订阅本次执行 | 事件流、Run 状态及持久历史 |
| SSE 重新订阅 | 订阅当前进程持有的 Run | 有界事件重放与实时事件 |
| Run 停止 | 请求取消本进程的运行 | 取消收尾与状态查询 |

接口失败可能发生在部分跨系统操作之后。部分清理任务可能已入队，不能一律按 HTTP 失败推断全部回滚。

任务结果具有保留期限；未知任务也可能表现为 PENDING。请求参数无效使用统一 422 响应，身份选择或授权失败按具体错误返回；流开始后通过 error 事件表达失败。

## 8. 接口范围与类型同步

当前没有直接向普通 HTTP 调用方开放任意 SQL 执行的端点，execute_sql 属于 Explorer 工具。Shell 和文件分析工具也通过 Agent 运行上下文绑定用户与 Conversation。

后端请求/响应模型是协议定义来源，前端生成类型随 OpenAPI 更新。接口清单记录方法、路径及操作语义，不复制整份请求模型；新增或删除路由需同步更新索引，行为变化同步到所属模块说明。
