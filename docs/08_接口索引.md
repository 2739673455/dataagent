# 08. 接口索引

前面的文档解释项目为什么这样工作。本页列出各页面使用的业务接口及其源码入口，便于开发时查阅。

## 1. 如何阅读接口

下表列出当前应用注册的全部业务 HTTP 操作。路径参数用 `{name}` 表示；参数位置、请求体、分页字段和响应结构以运行中的 `/docs` 或 `/openapi.json` 为准。默认本地文档地址为 `http://localhost:7000/docs`。

后端使用 Pydantic 定义接口数据，前端通过 OpenAPI 生成 TypeScript 类型。修改请求或响应时，应修改后端定义并重新生成类型，避免手动维护另一份相似结构。常规错误采用统一 Problem Details；流已经开始后的错误通过流事件表达，不能再简单替换 HTTP 状态码。

## 2. 认证

登录和刷新是获得令牌的入口；其他操作按路由要求验证当前身份。详见 [Identity](02_认证与授权.md)。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/api/v1/auth/login` | 登录并签发令牌 |
| `POST` | `/api/v1/auth/refresh` | 刷新访问令牌 |
| `POST` | `/api/v1/auth/logout` | 退出登录，撤销刷新令牌 |
| `POST` | `/api/v1/auth/change-password` | 修改当前用户密码 |
| `GET` | `/api/v1/auth/me` | 读取当前用户信息 |

## 3. 账号与 Doris 管理

这些操作需要平台管理员身份。Doris 管理动作使用后台管理连接，普通分析查询使用角色对应的查询身份。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/v1/admin/doris-roles` | 列出平台管理的 Doris 角色 |
| `POST` | `/api/v1/admin/doris-roles` | 创建 Doris 角色及查询身份 |
| `GET` | `/api/v1/admin/doris-roles/workload-groups` | 列出 Doris 资源工作组 |
| `GET` | `/api/v1/admin/doris-roles/existing` | 列出 Doris 中已有角色 |
| `PUT` | `/api/v1/admin/doris-roles/{role}/default` | 设置新用户的默认角色 |
| `DELETE` | `/api/v1/admin/doris-roles/default` | 清除默认角色 |
| `DELETE` | `/api/v1/admin/doris-roles/{role}` | 删除 Doris 角色 |
| `GET` | `/api/v1/admin/users` | 分页查询平台用户 |
| `POST` | `/api/v1/admin/users` | 创建平台用户 |
| `DELETE` | `/api/v1/admin/users/{user_id}` | 受理用户注销 |
| `PUT` | `/api/v1/admin/users/{user_id}` | 更新用户资料、状态或角色 |
| `GET` | `/api/v1/admin/doris-roles/{role}/select-grants` | 查询 SELECT 授权 |
| `POST` | `/api/v1/admin/doris-roles/{role}/select-grants` | 授予 SELECT 权限 |
| `DELETE` | `/api/v1/admin/doris-roles/{role}/select-grants` | 撤销指定 SELECT 权限 |
| `DELETE` | `/api/v1/admin/doris-roles/{role}/select-grants/all` | 撤销全部 SELECT 权限 |
| `GET` | `/api/v1/admin/doris-roles/{role}/row-policies` | 查询行级策略 |
| `POST` | `/api/v1/admin/doris-roles/{role}/row-policies` | 创建行级策略 |
| `DELETE` | `/api/v1/admin/doris-roles/{role}/row-policies` | 删除行级策略 |

## 4. 查询经验管理

管理员可以查看、禁用和删除经验。接口没有独立的“恢复经验”操作，恢复规则见 [Query](05_安全查询与经验沉淀.md)。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/v1/admin/query-experiences` | 分页筛选查询经验 |
| `POST` | `/api/v1/admin/query-experiences/batch-disable` | 批量禁用查询经验 |
| `POST` | `/api/v1/admin/query-experiences/batch-delete` | 批量删除查询经验 |
| `GET` | `/api/v1/admin/query-experiences/{experience_id}` | 读取单条查询经验 |
| `DELETE` | `/api/v1/admin/query-experiences/{experience_id}` | 删除单条查询经验 |
| `GET` | `/api/v1/admin/query-experiences/{experience_id}/executions` | 查看经验关联的执行记录 |
| `POST` | `/api/v1/admin/query-experiences/{experience_id}/disable` | 禁用单条查询经验 |

## 5. 对话与执行

这些接口校验登录身份和会话归属。流式接口使用 SSE；开始执行、订阅已有执行和停止执行是不同操作。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/api/v1/chat/create` | 创建草稿会话 |
| `POST` | `/api/v1/chat/delete` | 批量请求删除会话 |
| `DELETE` | `/api/v1/chat/draft/{conversation_id}` | 删除草稿会话 |
| `POST` | `/api/v1/chat/update` | 更新会话信息 |
| `GET` | `/api/v1/chat/ls` | 列出当前用户会话 |
| `GET` | `/api/v1/chat/ls/{conversation_id}` | 读取会话历史 |
| `GET` | `/api/v1/chat/{conversation_id}/subagents/{analysis_id}/{agent_type}/{session_id}/runs/{delegation_id}/messages` | 读取指定专家委派的消息 |
| `POST` | `/api/v1/chat/stream` | 发送消息并接收流式事件 |
| `POST` | `/api/v1/chat/{conversation_id}/resume` | 继续执行会话 |
| `GET` | `/api/v1/chat/{conversation_id}/run` | 查询当前 Run 状态 |
| `GET` | `/api/v1/chat/{conversation_id}/events` | 订阅当前 Run 的事件 |
| `POST` | `/api/v1/chat/{conversation_id}/stop` | 停止当前 Run |

## 6. 会话附件

附件访问同时受用户、会话及路径规则约束，客户端提供路径不等于获得任意文件访问权。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/api/v1/chat/attachment/upload` | 上传会话附件 |
| `POST` | `/api/v1/chat/attachment/delete` | 删除会话附件 |
| `GET` | `/api/v1/chat/attachment/get` | 读取或下载会话附件 |

## 7. 元数据管理

管理员维护业务目录并提交索引任务。同步任务已受理不等于 Elasticsearch 已完成更新。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/api/v1/meta/import` | 导入元数据 YAML，支持预检查 |
| `GET` | `/api/v1/meta/export` | 导出元数据 YAML |
| `GET` | `/api/v1/meta/tables` | 查询表目录 |
| `GET` | `/api/v1/meta/source-tables` | 查询 Doris 来源表 |
| `GET` | `/api/v1/meta/tables/{t_name}/columns` | 查询表的字段目录 |
| `GET` | `/api/v1/meta/metrics` | 查询指标目录 |
| `PUT` | `/api/v1/meta/tables/{t_name}` | 创建或更新表元数据 |
| `PUT` | `/api/v1/meta/tables/{t_name}/columns/{c_name}` | 创建或更新字段元数据 |
| `PUT` | `/api/v1/meta/metrics/{metric_name}` | 创建或更新指标元数据 |
| `POST` | `/api/v1/meta/tables/batch-delete` | 批量删除表元数据 |
| `POST` | `/api/v1/meta/columns/batch-delete` | 批量删除字段元数据 |
| `POST` | `/api/v1/meta/metrics/batch-delete` | 批量删除指标元数据 |
| `POST` | `/api/v1/meta/tables/sync` | 提交表内字段语义索引同步 |
| `POST` | `/api/v1/meta/tables/sync-values` | 提交表取值索引同步 |
| `POST` | `/api/v1/meta/columns/sync` | 提交字段语义索引同步 |
| `POST` | `/api/v1/meta/columns/sync-values` | 提交字段取值索引同步 |
| `POST` | `/api/v1/meta/metrics/sync` | 提交指标语义索引同步 |

## 8. 后台任务状态

任务状态查询需要管理员身份。Celery 任务结果具有保留期限，不能替代业务数据库中的持久状态。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/v1/tasks/{task_id}` | 查询后台任务状态 |
