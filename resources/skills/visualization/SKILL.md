# 图表与报告制作

## 从证据组织内容

- 先核对证据表的口径、单位、时间窗口、样本量和排序，再绘图；不填入未经计算的数字或预设业务结论。
- 报告先呈现核心结论与少量关键指标，随后展示对应图表、维度明细、限制与溯源。章节按任务需要取舍，不强制套用增长或下滑分类。
- 每张图回答一个明确问题；标题、坐标轴、图例和注释足以解释单位、区间与比较基准。
- 比率展示分母和样本量；区分绝对变化与相对变化。颜色含义保持一致，不单靠红绿区分系列。

## 图表渲染

使用角色提示词规定的 Python 渲染工具及沙箱字体。可采用以下样式起点，按标签长度与数据密度调整尺寸：

```python
import matplotlib.pyplot as plt

plt.rcParams.update(
    {
        "figure.dpi": 200,
        "font.family": "WenQuanYi Zen Hei",
        "axes.unicode_minus": False,
        "font.size": 10,
        "axes.spines.top": False,
        "axes.spines.right": False,
    }
)
```

优先使用清晰的趋势线、排序条形图或分布图。保持同组对比图的尺度一致，避免截断坐标造成误导；对异常值、缺失值及不完整周期明确标注。

## HTML 排版

- 遵循角色提示词中的自包含和静态报告约束。使用 UTF-8 与 viewport 元信息，内联 CSS 和 Data URI 图像。
- 数值和表格内容在生成阶段直接写入 HTML，页面无需执行脚本即可完整阅读。
- 按内容的重要性组织视觉层级，保持同级信息的尺寸与间距协调。布局根据可用宽度、内容数量和长度调整，不固定卡片数量、列数或实现方式。
- 正文、图例、代码和标签在各自背景上均须清晰可读；同时检查文字与背景颜色，避免局部样式或颜色继承降低对比度。
- 图像与文本适应容器尺寸，长内容合理换行；避免遮挡、裁切或意外溢出，让关键信息容易找到。
- 表格根据内容类型设置列宽、对齐和换行：文字易于阅读，数字便于比较，单位明确。宽明细表可在独立容器中水平滚动，关键结果不能因列宽或对齐方式而难以发现。
- 区分零值、缺失值和不适用值，说明无法计算的原因；不使用空白或“检查通过”掩盖必要结果缺失。
- 复杂口径、方法和限制可放入原生 `<details>`；关键结论不能仅藏在折叠区。
- 溯源说明业务表、指标、周期与样本，不把容器文件路径当作用户可访问的链接。配套文件通过文件交付协议提供。
- HTML 文本按需要转义，不把数据值直接拼成标签。不得留下模板占位符、假图像或虚构的“校验通过”标记。

## 验收

1. 核对图表、正文与证据表的数字、单位、排序、图例和时间轴。
2. 检查 HTML 不依赖外部资源，图像实际嵌入且可解码，没有脚本或动态执行标签；表格结果完整，缺失值有明确解释。
3. 模型提供 `view_image` 时，查看生成的图像；HTML 有可用渲染工具时，在代表性的宽屏和窄屏尺寸下检查页面。检查文字对比度、布局层级、内容边界、表格可读性与关键结果可见性；源码中有数据不能替代展示验收。
4. 发现问题后修正生成代码或样式，重新生成并复查；共用样式调整后也检查其他受影响区域。
5. 未能实际查看图像或渲染 HTML 时，明确说明已完成的程序检查与尚未完成的视觉检查，不声称已经通过视觉验收。
