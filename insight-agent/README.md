# 使用指南

## 项目配置

- 后端运行配置：`configs/config.yml`
- 后端环境变量：`configs/.env`

后端主要配置项在 `configs/config.yml`：

- `db`：MySQL 连接信息
- `redis`：Redis 连接信息
- `lm_config`：大模型与推理参数
- `mcp`：外部 MCP 工具地址
- `auth_service`：认证服务地址与 introspection 接口
- `data_agent`：数据查询服务地址
- `cors_origins`：允许跨域的来源列表
- `port`：Insight Agent 后端监听端口，当前默认 `7300`

`configs/.env` 用于补充敏感环境变量，例如：

- `APP_DB_PASSWORD`
- `REDIS_PASSWORD`
- `OPENROUTER_API_KEY`
- `TAVILY_API_KEY`

前端构建产物默认放在 `app/static/dist`，后端启动后可直接提供静态页面。

## 快速开始

### 1. 安装后端依赖

```bash
uv sync
```

### 2. 准备配置

确认以下文件存在并已填写：

```bash
configs/
├── .env
└── config.yml
```

### 3. 启动后端

```bash
uv run -m app.main
```

# 案例

## 商品转化率降低原因分析
发现销售额突然下降，询问：为什么转化率下降了？
1. 分析90天内转化率，确定下降的开始时间
2. 按流量来源、设备类型、地理位置分段，定位受影响的分段
3. 发现在某月某天，移动端用户数量出现下降
4. 检查最近网站部署情况，发现这一天支付网关更新
5. 交叉对比客户反馈数据，发现移动端用户报告的支付错误增加
6. 结论是新支付网关集成导致出现结账失败

## 产品目录优化
分析商品目录质量、属性缺失和描述不一致对搜索曝光与转化表现的影响，定位拖累商品发现和成交的关键因素。  
作用和目的：提升商品信息质量，提高搜索可见度、点击率和转化率。  

## 客户行为分析
分析用户购物路径、废弃购物车和历史购买行为对转化结果的影响，识别不同人群和品类的关键流失环节与机会点。  
作用和目的：支撑个性化运营和分层触达，提升重点人群与重点品类的转化效率。  

## 智能库存管理
分析销量变化、季节性波动和供应链约束对库存结果的影响，识别缺货风险和积压风险的主要驱动因素。  
作用和目的：提升库存预测准确性，在优化营运资金的同时避免缺货和库存过剩。  

## 评论和反馈处理
分析用户评论中的情绪、产品问题和建议对复购、退货和品牌口碑的影响，定位最值得优先处理的产品与服务问题。  
作用和目的：加快产品改进与服务响应，降低负面反馈扩散风险并改善用户满意度。  

## 市场表现分析
分析多渠道销售表现差异及其背后的流量结构、转化效率和商品供给因素，定位各平台增长或下滑的主要原因。  
作用和目的：发现渠道优化机会，制定统一且可落地的跨渠道经营策略。  

## 退款模式检测
分析退款、退货与用户反馈之间的关联，识别产品质量、描述不一致和履约问题对退款成本的主要驱动作用。  
作用和目的：提前发现高退款风险点，降低退款损失并持续优化商品与履约体验。
