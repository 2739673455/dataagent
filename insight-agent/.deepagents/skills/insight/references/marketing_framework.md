# 营销分析框架

当任务是活动复盘、618/双11 等大促分析、粉丝活动分析、私域运营分析时，优先按下面框架组织。

## 1. 先确认分析目标

常见目标：

- 拉新：新客占比、新客成本、新客转化
- 激活：老客回流、沉睡唤醒、复购提升
- 提效：客单价、连带率、优惠效率
- 爆款：重点商品、重点品类、资源倾斜

## 2. 默认分析维度

### 用户画像

- 新客/老客占比
- 年龄分布
- 性别分布
- 会员等级
- 购买力分层
- 城市等级

### 经营结果

- 下单用户数
- 订单量
- 销售额
- 客单价
- 件单价
- 转化率
- 复购率

### 地域表现

- 省份/城市销售额与用户数
- 区域贡献占比
- 高转化区域与低渗透区域
- 新客重点区域与老客优势区域

### 优惠表现

- 不同优惠形式覆盖人数
- 券核销率
- 优惠对客单价的影响
- 优惠对新客拉动与老客复购的差异

### 商品表现

- 品类/品牌/SPU/SKU 销售额
- 热销商品、潜力商品、低转化高曝光商品
- 商品与优惠的搭配效果
- 商品与人群的匹配度

### 时间与渠道

- 分天趋势
- 分时段趋势
- 预热、爆发、返场表现
- 渠道来源贡献

## 3. 常见交叉分析

- 新老客 x 优惠形式
- 新老客 x 商品品类
- 地域 x 商品偏好
- 会员等级 x 客单价
- 购买力 x 优惠敏感度
- 渠道 x 转化率

## 4. 输出建议模板

每个部分尽量按这个顺序写：

1. 一句话结论
2. 关键数字
3. 业务解释
4. 营销建议

例如：

- 华东区域贡献销售额最高，但新客占比低于整体均值，说明该区域以老客复购为主。618 可针对华东追加会员复购券，对华南则增加新客拉新礼包。

## 5. 618 营销建议的常见结构

- 拉新：新客礼金、首单券、裂变奖励、达人种草
- 转化：限时券、满减门槛优化、凑单推荐、爆款带动
- 客单价：跨品类组合购、加价购、满赠
- 复购：老客专属权益、会员积分、周期购提醒
- 区域：重点城市差异化投放
- 商品：爆款引流、利润款承接、长尾款清仓

## 6. 文件产物建议

- `analysis/*.csv`: 各维度汇总表
- `analysis/report_payload.json`: HTML 渲染输入
- `outputs/*.html`: 可分享的最终报告
