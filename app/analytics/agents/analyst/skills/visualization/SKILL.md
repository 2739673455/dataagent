# 数据可视化与 HTML 报告

## 工作目标

把当前 Analyst Session 中已经验证的指标、证据表和分析结论转化为准确、清晰、可独立交付的展示产物。

## 职责边界

- 直接使用 Analysis Skill 生成并验证过的汇总指标、归因结果和证据表
- 只做展示所需的格式化与映射，例如千分位、百分比、排序、标签和 HTML 表格渲染
- 不为排版重新聚合底层数据，不改变指标口径，不生成缺少证据支持的新结论
- 必要的汇总字段、粒度或指标缺失时，先补充分析步骤并重新验证结果
- 图表和报告中的所有数字必须能够追溯到证据表和计算脚本

## 图表规范

- 使用 Python、Matplotlib 或 Seaborn 生成高清静态 PNG 或 SVG
- 根据问题选择图形，避免用复杂图形装饰简单关系
- 校验标题、指标口径、单位、图例、排序、颜色、时间轴和数据标签
- 同一指标在报告内保持一致的颜色、单位和小数位
- 中文字体使用 WenQuanYi Zen Hei；Matplotlib 设置 `font.family = "WenQuanYi Zen Hei"` 和 `axes.unicode_minus = False`
- Pillow 使用 `/usr/share/fonts/truetype/wqy/wqy-zenhei.ttc`
- 不探测网络、不下载字体、不生成自定义点阵字形

## 最终报告规范

最终报告统一生成为自包含 HTML：

```text
report_v1.html
charts/
└── key_metric_v1.png
```

- 样式使用内联 CSS
- 图表使用 data URI 嵌入 HTML，报告不依赖外部图片、样式或脚本文件
- 禁止使用 `script` 或其他动态执行标签
- 报告包含分析背景、指标口径、核心结论、证据表格、关键图表、限制和数据来源追溯
- Markdown、PDF 和 Office 文档不能替代最终报告
- PNG、SVG、CSV 和 Parquet 可以作为 HTML 报告的配套产物
- 对外共享文件使用不可变版本名

## 标准流程

1. 读取分析脚本、证据表、结论和限制说明，确认使用的是最终验证版本
2. 建立结论到证据表字段及图表的对应关系
3. 生成图表并逐项核对数字、单位、排序、日期和文字说明
4. 生成自包含 HTML，把关键证据、结论和图表组织成完整阅读路径
5. 独立打开 HTML，检查图片、样式、中文、布局和内容是否完整
6. 将 HTML 及必要的配套文件写入 `artifacts`

## 完成标准

- 最终 HTML 可以独立打开，样式和图表均已内嵌
- 所有展示数字与已验证证据一致
- 图表不存在乱码、截断、错误单位或误导性坐标轴
- 报告明确给出指标口径、数据范围、限制和来源
- 最终报告已列入 `artifacts`，路径使用 `/sessions/...`
