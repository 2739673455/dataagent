# 案例
## 商品转化率降低原因分析：
发现销售额突然下降，询问：为什么转化率下降了？
1. 分析90天内转化率，确定下降的开始时间
2. 按流量来源、设备类型、地理位置分段，定位受影响的分段
3. 发现在某月某天，移动端用户数量出现下降
4. 检查最近网站部署情况，发现那一天支付网关更新
5. 交叉对比客户反馈数据，发现移动端用户报告的支付错误增加
6. 结论是新支付网关集成导致出现结账失败
